# EduNova

EduNova is an educational management web application developed with ASP.NET Core MVC.

## Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- HTML / CSS / JavaScript

## Features

- User authentication and login
- Role-based dashboards
- Admin, Teacher, and Student roles
- Course management
- Course enrollment
- Lesson and course material management
- Database integration with Entity Framework Core
- Session-based user management

## Project Structure

The project follows the ASP.NET Core MVC architecture and includes:

- Controllers
- Models
- Views
- Data
- Migrations
- wwwroot

## About

This project was developed as a practical educational software project to learn and apply C#, ASP.NET Core MVC, SQL Server, and Entity Framework Core.
